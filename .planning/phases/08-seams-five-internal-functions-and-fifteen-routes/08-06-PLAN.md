**D-130 — AC-10 lands in two halves, and this plan ships the half that can run and says plainly that
it is a half.**

Chosen: `tests/security/test_every_route_declares_an_action.py` — the lock file's own `test_ref` —
asserts, over `assembled_routes(app)`:

1. **the mechanism**, which is the operative clause and is complete today: a route declaring no action
   **fails** rather than being skipped, defaulted, or treated as unauthenticated. Four exemptions
   exist, all enumerated with reasons, and the set of routes declaring nothing is asserted to be
   **exactly** those four in both directions;
2. **the vocabulary bridge**, which is new and is what makes clause 1 mean something: every
   `ManagementAction` member carrying no module prefix is a row in the live `access.role_permission`
   table, and the members carrying a prefix are exactly call-ledger's five, exempted by name with
   ADR-0018 cited;
3. **a mutation control**: a route added to a throwaway `FastAPI` instance with no `declares_action`
   makes the assertion fail. Without it the test can pass because the walk found nothing, which is
   precisely Broken Window #4's failure and precisely what `assembled_routes()` exists to prevent.

**What does not land, stated rather than implied:** *"every route in **every** module"* is a property
of the assembled table with all eight modules mounted, and `.planning/research/PITFALLS.md` §5 is
explicit that it *"cannot actually run until every module is mounted — i.e. not before phase 23."*
Two of eight are mounted. The test's own docstring says so, names Phase 23, and uses the shared
helpers (`assembled_routes`, `declared_action`, `declares_session`) **so Phase 23 widens a test rather
than inventing one** — which is the reason those helpers were put in `session_auth.py` in Phase 2
rather than in the test that first needed them.

Rejected: **claiming the criterion complete.** It would be the one defect in this phase that nobody
downstream could see: a green test named after a criterion it only half asserts is worse than a
missing test, because the missing one gets written.
Rejected: **deferring the whole criterion to Phase 23.** The mechanism is what a later module copies,
and six more modules would each invent their own declaration convention in the meantime. The
mechanism ships now; the census ships at 23.
Rejected: **putting the assertion in `tests/architecture/test_route_table.py`.** 06-02's D-84 refused
the same thing for AC-7 and the reason holds here: that file's `EXPECTED_ROUTES` literal moves every
phase, so a criterion parked in it has neighbours that change under it.
Reversibility: **cheap.**
