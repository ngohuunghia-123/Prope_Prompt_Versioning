# A-007 — Working role set: Owner, Reviewer, Viewer, Admin

**Statement**: Until the real matrix is signed off, the MVP uses four roles. Owner may edit their own
prompts and submit revisions. Reviewer may approve or request changes on revisions they did not
author. Viewer may read prompts they have been granted access to. Admin may transfer ownership and
release. Edit, approve, and release are three distinct permissions, not one.

**Rationale**: NFR-01 fixes the required separation; this is the smallest role set that expresses it.
It is a placeholder for OQ-006, not a policy.

**Impact if wrong**: Permission checks are centralised, so a different matrix is a change in one
module — but any role removed after prompts exist requires a data migration.
