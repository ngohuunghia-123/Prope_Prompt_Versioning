# A-041 — The released pointer is a field on the prompt property, writable only by release-control

**Statement**: The identity of the currently released revision is stored on the prompt property record,
which `prompt-registry` owns. `release-control` is the only module permitted to change it, through a
single `set_released_revision(prompt_id, version_id, release_id)` command. No module reads release or
approval records to answer "what is running right now".

**Rationale**: Both modules have a claim on this value, which is the shape a dependency cycle takes.
Putting the field in the registry makes the gateway's resolution a single read on the hot path, which
is what the p95 50 ms budget in `00_context.md` can afford; the alternative — gateway asks
release-control, then asks the registry for the body — doubles the reads on the one path where latency
was declared non-negotiable. Restricting the write to release-control keeps the invariant that a
release is a recorded decision (BR-04) rather than a field anyone can set.

**Impact if wrong**: A column moves and one command changes hands. ~~It becomes moderate rather than
cheap only because the gateway cache invalidation (A-031) is keyed to this write.~~

> **Corrected 2026-08-09 (step 4, release-control's stack pass).** There is no cache invalidation keyed
> to this write, and there never was — ADR-0012 found that no mechanism existed and decided the entry
> simply expires. What is actually keyed to this write is the gateway's **cache key**,
> `(workspace_id, model_name, pin)`, and the resolve read behind it. So the reversibility rating stands
> at *moderate*, but for a plainer reason: moving the column changes one command's signature, one read
> in the gateway's hot path, and the shape of that key. Nothing has to be un-wired, because nothing was
> wired.
>
> This was the sixth live "the cache invalidates" claim found in the same pass — with
> `release-control.lock.yml` (three), ADR-0009 and ADR-0001. **Deleting a mechanism is a documentation
> sweep**, and ADR-0012's deletion reached two locks and three other files. ADR-0041 recorded the
> identical lesson about the spill file one pass earlier.
