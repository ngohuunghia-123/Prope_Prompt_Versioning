# A-050 — Prompt body ≤ 32 KiB; change summary required, ≤ 200 chars

**Statement**: A prompt body is rejected above 32 KiB. A change summary is mandatory on every revision
and capped at 200 characters. Both are enforced at the edge with a message naming the actual size;
neither is ever silently truncated.

**Rationale**: 32 KiB is roughly 8,000 tokens — far past any realistic system prompt and small enough to
keep the 300 ms diff target and the resolution cache honest. The change summary is mandatory because
the reviewer's screen is built around answering "what changed and why", and an optional field on a
review workflow is an empty field. Silent truncation is forbidden outright: corrupting a prompt body is
corrupting the asset the product exists to protect.

**Impact if wrong**: Two numbers in a validator.
