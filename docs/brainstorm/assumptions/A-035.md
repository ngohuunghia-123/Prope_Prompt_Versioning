# A-035 — The fallback answer is optional; without one, the upstream error passes through

**Statement**: A revision may have no fallback answer. In that case an upstream failure returns the
provider's error, translated into the OpenAI error shape. Release is not blocked on having a
fallback; the review screen shows whether one is set.

**Rationale**: Not every prompt can be answered generically — a prompt that extracts structured data
has no sensible canned reply, and inventing one would be worse than an honest failure. Making it
optional also keeps the feature from becoming a checkbox someone fills with placeholder text to get
past a gate.

**Impact if wrong**: Making it mandatory is a validation rule at release time.
