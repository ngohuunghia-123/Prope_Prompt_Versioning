# A-059 — A prompt may have an empty or partial eval suite; the review screen says "no eval suite", never "pass"

**Statement**: A prompt property may exist, be revised, be approved, and be released with zero eval
cases. The comparison screen for a prompt with an empty suite displays "no eval suite" and no pass/fail
column at all. A suite below the 10-case guideline runs normally and displays its case count. Absence of
evidence is never rendered as a green result.

**Rationale**: `00_context.md#scope` describes 10–20 hand-authored cases as the shape of a suite, not as
a precondition for registration — and requiring 20 cases before a prompt can be released would block the
first prompt anyone registers, including the demo. The rule that matters is the display one: a screen
that shows "0 failing" for a prompt with no cases is stating a measurement that was never taken, which
is the same claim `00_context.md#constraints` forbids in stronger form ("no surface may claim the eval
guarantees no quality degradation").

**Impact if wrong**: One branch in the renderer. Requiring a minimum suite size later is a policy check
in release-control, not a schema change here.
