# A-015 — Feature 2 ships as a line-level textual diff, not a consequence-language diff

**Statement**: The diff screen shows a side-by-side, line-level textual comparison of two revisions'
bodies, plus a field-level comparison of details (owner, tags, access, variables). The
"consequence-language diff" described in the positioning — a generated explanation of what the
change will do — is out of scope for the MVP.

**Rationale**: Feature 2 as requested is "compare the old prompt and the new prompt", which a
textual diff satisfies exactly. The consequence-language version requires a generation step whose
output would itself need review, and `positioning.md` §6 warns against generic model-written
"improvements". Shipping the literal ask first keeps the review screen honest.

**Impact if wrong**: The generated explanation is an additive panel on an existing screen, but the
demo narrative in `BRIEF.md` §10 item 4 promises it — so if the demo needs it, that is a scope
decision to raise, not a silent addition.
