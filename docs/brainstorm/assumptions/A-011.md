# A-011 — A prompt body is one plain-text field with optional {{variable}} placeholders

**Statement**: In the MVP a prompt is a single text body, delivered to the provider as the system
message. Variables are written as `{{name}}` and declared with a default value used when running the
eval suite. Multi-message chat templates (system/user/assistant arrays) and tool definitions are out
of scope. Provider, model, and generation parameters are **not** out of scope — they live on the
revision (A-024); this assumption is about the shape of the body only.

**Rationale**: The primary persona is a marketer or designer writing a block of instructions, and
`prope_source_of_truth.md` §4.1 requires them to work without code. A single text body also makes
the diff screen (feature 2) trivially correct. Nothing in the source documents describes prompts as
structured message arrays.

**Impact if wrong**: The body column becomes structured, and the diff renderer has to be rewritten.
Contained to two modules but not cheap.
