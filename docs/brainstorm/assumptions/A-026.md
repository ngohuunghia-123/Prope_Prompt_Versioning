# A-026 — The gateway implements chat completions only, with streaming, and OpenAI-shaped errors

**Statement**: The MVP gateway serves `POST /v1/chat/completions` (both streaming and
non-streaming) and `GET /v1/models`, which lists the prompt properties the caller may access. Every
other OpenAI route returns `501` with an OpenAI-shaped error body. Error responses match OpenAI's
schema so that client SDKs raise their normal exception types rather than failing to parse.

**Rationale**: `GET /v1/models` is what most OpenAI clients call to validate configuration, and it
is a free registry read. Chat completions is the only surface the described use case needs. Matching
the error schema matters as much as matching the success schema: an SDK that cannot parse the error
turns a clear 403 into an unexplained crash inside the consumer's app.

**Impact if wrong**: Additional routes are additive.
