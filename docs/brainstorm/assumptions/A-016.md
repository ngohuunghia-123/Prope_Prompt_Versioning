# A-016 — Cost delta warns at +20% and never blocks

**CONFIRMED BY THE USER 2026-08-09** (OQ-009 resolved, option 1). The threshold is no longer a
placeholder: 20% is the decided default, and blocking on cost stays off and configurable. The one
gate that can refuse a release remains BR-03's Approved-only database constraint, and it remains the
only one.

**Statement**: If the candidate revision's eval-suite cost exceeds the trusted revision's by 20% or
more, the review screen shows a warning above the decision buttons. The release is never blocked on
cost in the MVP. The threshold and the block behaviour are configuration values, defaulting to
20% and off.

**Rationale**: `BRIEF.md` §5③ prescribes "delta plus warning, no hard block" for the MVP and FR-08
requires the policy to be configurable. 20% is a placeholder chosen to be large enough not to fire on
noise and small enough to fire before a 40%-style regression ships; the number itself is OQ-009.

**Impact if wrong**: A configuration value.
