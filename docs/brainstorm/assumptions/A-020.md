# A-020 — Proposed default: no real corporate prompts until the security baseline is signed off

**Statement**: Until the RBAC matrix, data classification, retention period, and sensitive-content
rule are agreed, the system holds only synthetic prompts and prompts volunteered by team members as
non-sensitive. This includes the demo.

**Rationale**: `business-analysis.md` §11 rates the missing baseline as Critical and states the rule
without qualification: settle it before importing real prompts. `positioning.md` §12 repeats it.
This assumption is the only way to keep building while OQ-006 is open without violating that rule.

**Impact if wrong**: If real prompts are needed sooner, the baseline work moves earlier — it does not
disappear.
