# A-003 — All timestamps are stored and exchanged as RFC 3339 UTC

**Statement**: Every timestamp in the database, the API, and the audit log is RFC 3339 with an
explicit UTC offset. Local-time rendering happens in the UI only.

**Rationale**: Prevailing convention, and the audit trail (NFR-02) is worthless if two events cannot
be ordered. No competing default follows from anything in the source documents.

**Impact if wrong**: Display-layer change only.
