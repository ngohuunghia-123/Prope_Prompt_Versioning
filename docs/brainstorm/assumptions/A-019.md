# A-019 — Proposed default: the demo runs locally via docker-compose

**Statement**: The deploy target is a local `docker-compose` stack on the presenting machine. No
public URL, no TLS, no managed database, no data-residency requirement.

**Rationale**: The repository already ships a `Dockerfile` and a `docker-compose.yml`, so this is the
path of least resistance and it costs nothing to reverse early. Nothing in the surviving documents
states a hosting requirement — the organiser's setup guide has been deleted from the working tree.

**Impact if wrong**: Hosting is a day of work if discovered early, more if discovered late — which is
why OQ-011 exists rather than this assumption standing alone.
