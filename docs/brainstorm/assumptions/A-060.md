# A-060 — With no released revision there is no baseline; the run is reported absolutely and the delta is omitted

**Statement**: When a prompt has no `released_version_id` — the first release of a new prompt — no
baseline run is dispatched. The candidate run is reported on its own: per-case pass/fail and the run's
absolute token and money totals. The cost-delta row is omitted with the label "first release, no
baseline", and the +20% warning (A-016) cannot fire.

**Rationale**: A delta needs two measurements. Presenting the first run as "+100%" against a zero
baseline would be arithmetically defensible and completely misleading above a decision button, and
presenting it as "0%" would be worse. Omission with a stated reason is the honest rendering, and it
follows the same principle as A-057's withheld delta: a blank with an explanation beats a plausible
wrong number.

**Impact if wrong**: One branch in the comparison query and one label. Showing the absolute cost against
a budget target instead is additive.
