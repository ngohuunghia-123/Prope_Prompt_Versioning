# A-115 — The action vocabulary is a closed list, and an unknown action is denied

**Statement**: `may()` accepts actions from one enumerated list held in access-control, and an action
not on it returns **deny**, not error and not allow. The MVP list is:
`prompt.read`, `prompt.create`, `prompt.edit`, `prompt.retire`, `prompt.transfer_owner`,
`prompt.grant`, `revision.create`, `suite.read`, `suite.edit`, `run.start`, `run.read`,
`revision.submit`, `revision.approve`, `release.create`, `release.break_glass`, `release.withdraw`,
`provider.configure`, `provider.rotate_credential`, `provider.disable`, `catalogue.read`,
`workspace.manage_members`, `workspace.manage_keys`, `price.manage`, `spend_ceiling.manage`,
`user.tombstone`.

`user.tombstone` was added 2026-08-09 when OQ-017 was answered (ADR-0054). It is deliberately a
separate action from `workspace.manage_members` rather than folded into it: removing a person from a
workspace is reversible and workspace-scoped, while tombstoning an account is irreversible and
account-scoped, and one permission covering both would let a workspace admin erase a person who
still works elsewhere in the group. This is the closing sentence of this assumption doing its job —
the list had to be edited to grow, and editing it is the moment someone decides who holds it, which
here is OQ-006's matrix.

**Rationale**: Default-deny at the vocabulary level, not just at the matrix level. A string-typed action
parameter means a typo, a renamed constant, or a newly added feature can fall through to a branch nobody
wrote — and every one of those failures is silent in the allow direction. Enumerating makes adding a
feature require touching the list, which is the moment someone decides who should hold it.

The list is derived from the endpoints the six dependent locks already declare, plus the five
release-control permissions the constraints table calls non-negotiable, plus A-081's key management and
call-ledger's two admin surfaces. It is not a guess at a role matrix — that is OQ-006 — it is the set of
things the system can currently be asked to do.

**Impact if wrong**: Adding an action is a row. The list will grow; that it must be edited to grow is the
feature.
