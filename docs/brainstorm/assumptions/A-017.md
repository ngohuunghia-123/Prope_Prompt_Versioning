# A-017 — Individual mode is out of the MVP and comes after it

**CONFIRMED BY THE USER 2026-08-09** (OQ-007 resolved, option 1), with one addition the default did
not carry: individual mode is **scheduled after the MVP**, not abandoned. H-07 stays untested this
cycle knowingly.

**Statement**: The build implements the enterprise flow only. The individual save → find → reuse
experience described in `prope_source_of_truth.md` §4.4 is not built, and hypothesis H-07 is not
tested in this cycle.

**Rationale**: The five requested features are all enterprise-flow features, and §4.4 forbids
exposing the governance model as the personal default — meaning individual mode is a second surface,
not a filter over the first. `BRIEF.md` §12 names scope as the second-largest risk.

**Impact if wrong**: Adding it later is a new surface over the same registry, which is additive; but
deciding it late wastes the design work spent on enterprise-only screens.
