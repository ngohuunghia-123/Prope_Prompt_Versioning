# A-001 — The feature request's "version / rollback / promote" render as revision / restore / release

**Statement**: In every user-facing surface the words are **revision**, **restore**, **release**,
and **grant access**. `Version ID` is retained in API and release contexts; `rollback` is retained
in API and technical documentation only. Statuses stay literal: Draft, In review, Approved, In use,
Retired.

**Rationale**: `prope_source_of_truth.md` §8 and §18 rules 8–9 mandate this vocabulary and declare
themselves canonical over every other document. The feature request used the generic words; this is
a translation, not a change of meaning.

**Impact if wrong**: Copy-level rename. No structural effect.
