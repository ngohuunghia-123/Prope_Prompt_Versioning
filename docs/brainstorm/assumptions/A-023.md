# A-023 — One environment in the MVP: a single released pointer per prompt

**Statement**: Each prompt property has exactly one release pointer. There are no `dev`, `staging`,
and `production` aliases. A revision is either the released one or it is not.

**Rationale**: `prope_source_of_truth.md` §16 excludes full environment orchestration from the MVP
and S7 places aliases in Release 3. With pinning available (A-022), a developer who wants to try a
candidate can pin to it explicitly, which covers the staging need without a second pointer.

**Impact if wrong**: The pointer becomes a table keyed by environment, and every release, restore,
and usage record gains an environment column. Real work, but mechanical.
