# A-029 — Spend ceilings exist but default to off

**Statement**: A workspace may set an optional monthly spend ceiling and an optional per-eval-run
ceiling. Both default to off. When a ceiling is set and reached, eval runs are refused and gateway
traffic is not, on the grounds that refusing production traffic to save money is a worse failure
than the overspend.

**Rationale**: BYOK (OQ-004) makes the spend the workspace's own, so a mandatory cap would be Prope
imposing a policy on someone else's budget. A ceiling still needs to exist because an eval suite of
20 cases run in a retry loop is the obvious way to burn a key by accident.

**Impact if wrong**: A default flag.
