# A-022 — A bare model name resolves to the released revision; `name@<n>` pins

**Statement**: `ecom/agent-pipeline` resolves to whichever Approved revision is currently released.
`ecom/agent-pipeline@7` pins to revision 7, and `ecom/agent-pipeline@<version_id>` pins to an exact
version ID. A pinned revision that is not Approved is refused. An unknown name, an unreleased
prompt, or a caller without access returns an OpenAI-shaped error naming the specific reason —
never a fallback to some other revision.

**Rationale**: The user's answer fixes the bare-name behaviour ("phiên bản mới nhất đã được
promote"). Pinning is required by H-05 and S7 and costs one parse. Refusing rather than falling
back is BR-03: an unapproved revision must never reach production, and a silent substitution is the
worst possible way to break that rule.

**Impact if wrong**: A change in the resolver's parse step.
