# A-073 — The break-glass follow-up task never auto-closes and never expires

**Statement**: The review task A-009 creates on a break-glass release is due 24 hours later and stays
`open` until a person closes it with a recorded note. It does not close on a timer, does not expire, and
is not archived by age. Overdue tasks are counted by `prope_release_review_task_overdue` and alerted on.

**Rationale**: The 24-hour follow-up is the only thing that keeps break-glass exceptional. A task that
tidies itself away after a week converts the escape hatch into a free one, which is exactly the drift
A-009's `revisit_when` is watching for. An overdue count that keeps rising is uncomfortable on purpose —
it is the number that shows whether the approval gate is real.

**Impact if wrong**: A scheduled job to add. Note that the reverse is not symmetric: tasks already
auto-closed cannot be un-closed, which is why the default is to keep them open.
