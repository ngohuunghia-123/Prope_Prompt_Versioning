# A-070 — An unavailable review summary is treated like failing evidence: the reason becomes mandatory

**Statement**: When release-control cannot pull `get_review_summary()` — evaluation is down, or the run
never completed — the review screen states that the evidence could not be loaded, and the approve action
requires an `acknowledgement_reason` exactly as it would if `requires_acknowledgement` were true. The
approval is never blocked (ADR-0005 applies unchanged); it is never frictionless either.

**Rationale**: The dangerous default is the silent one. With no rule, an absent eval panel behaves
identically to a fully passing one, and the system converts "we do not know" into "it is fine" without
anybody choosing that. Unknown evidence is closer to failing evidence than to passing evidence, and the
cost of being wrong in this direction is ten seconds of typing.

**Impact if wrong**: One branch in the validation of one field.
