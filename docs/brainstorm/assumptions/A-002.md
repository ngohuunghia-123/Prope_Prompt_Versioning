# A-002 — A revision is immutable, numbered per prompt, and carries an opaque global version ID

**Statement**: Editing a prompt never mutates an existing revision. Each revision has a
monotonically increasing integer `revision_number` scoped to its prompt (shown to users) and an
opaque globally unique `version_id` (used by APIs, releases, and audit records). Both are assigned
at creation and never reused.

**Rationale**: BR-06 requires immutable snapshots with editor and timestamp; H-05 requires every
release to carry a version ID. A human-readable per-prompt number is what makes a diff screen
speakable ("revision 4 vs revision 7"); the opaque ID is what makes a release traceable.

**Impact if wrong**: Migration of the identifier column and every reference to it. Contained to the
registry module, but not free.
