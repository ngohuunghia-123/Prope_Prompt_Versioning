# A-006 — Cost delta is measured over one full eval-suite run, candidate vs. trusted revision

**Statement**: The cost delta is the difference in input tokens, output tokens, and money between
running the whole eval suite on the candidate revision and running the same suite on the current
trusted revision. Retries are counted. It is never derived from the length of the prompt text.

**Rationale**: BR-07 and `BRIEF.md` §5③ forbid inferring cost from prompt length, citing a case
where a 17% input-token cut produced a 67% session-cost increase. The ideal unit — cost per
successfully completed production task — needs telemetry that this MVP does not have (S9 is P2). A
fixed suite executed identically against both revisions is the closest honest approximation
available, and it must be labelled as such on screen.

**Impact if wrong**: The number is still directionally useful; replacing it later means changing the
measurement source, not the display.
