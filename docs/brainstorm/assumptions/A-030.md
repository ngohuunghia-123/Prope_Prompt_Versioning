# A-030 — Only providers that return a usage object are supported

**Statement**: A provider may be registered only if its chat-completions response reports input and
output token counts. Prices are entered per provider-model in the dashboard and stored with an
effective date, so a historical cost figure stays reproducible after a price change. Prope never
estimates tokens by counting characters.

**Rationale**: BR-07 forbids inferring cost from prompt length, and the success metric "within ±2%
of provider-reported usage" is unmeasurable against a provider that reports nothing. Making it a
support condition rather than a silent degradation keeps the cost delta honest. Effective-dated
prices exist because without them, yesterday's approved cost comparison silently changes when
someone edits a price today.

**Impact if wrong**: Supporting a usage-free provider means adding a clearly-labelled estimate mode,
which is additive but must never be the default.
