# A-005 — Pass/fail is computed only from deterministic assertions; subjective quality is displayed, never scored

**Statement**: An eval case passes or fails on code-decidable assertions only: exact match,
substring, regex, JSON-schema validity, required phrase, forbidden phrase, maximum length, maximum
latency, maximum cost. Where quality is subjective, the screen shows the old and new outputs side by
side for the reviewer to judge. No score, no LLM judge, in the MVP.

**Rationale**: `BRIEF.md` §8 forbids promising that eval guarantees no quality degradation, and
BR-08 restricts blocking to deterministic criteria. `positioning.md` §4 records that judge
correlation is near zero on creative content — which is exactly what the primary persona writes.

**Impact if wrong**: The assertion set is extensible; adding a judge later is additive. But a suite
authored against these assertion types would need re-authoring if scoring became the unit.
