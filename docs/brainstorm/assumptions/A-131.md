# A-131 — The backup destination is a second group-controlled machine, and there may not be one yet

**Statement**: ADR-0036's nightly `pg_dump` is copied to a second machine the group controls, retained
30 days, with `.env` sent to a different destination on a different schedule. **If no second machine
exists when the pilot opens**, the dump is written to the VM's own disk and copied by hand at pilot
review, and the deployment runs with an on-host-only backup until one is provisioned. This assumption is
the record of that gap.

**Rationale**: OQ-011 resolved the deploy target as one group-controlled Linux VM and answered residency
*"by consequence — nothing leaves the host."* That answer is what excludes object storage as the
destination (ADR-0036), and it is also what leaves the destination unnamed: the question never asked
whether the group has a second machine, because until step 4 nothing needed one.

Object storage would resolve this in one `rclone` line, and it is deliberately not taken. A dump
contains prompt bodies, stored request and response bodies (ADR-0018, A-040), and encrypted provider
credentials — the largest single collection of everything ADR-0030 declined to send off-box for
telemetry and ADR-0033 declined to hand to a managed platform. A backup channel is not an exception to a
residency answer.

The gap is recorded rather than closed because it is a fact about the user's environment, not a decision
the pack can make. Guessing a destination would put a hostname in an ADR that nobody can reach.

**Impact if wrong**: If no second machine appears, the pilot runs with backups that protect against a
bad migration and not against losing the host — and under A-121, losing the host loses every audit event
Prope has ever recorded. That is a materially worse position than ADR-0036 describes, which is why it is
written here in the same words rather than left implied by an unconfigured cron. Closing it costs one
`scp` target and a key; it is cheap in every direction except the one where nobody notices it is open.
