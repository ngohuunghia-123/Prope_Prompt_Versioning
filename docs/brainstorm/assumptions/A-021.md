# A-021 — The model name is `namespace/name`, unique per workspace, and immutable once created

**Statement**: Every prompt property has a model name of the form `namespace/name`
(e.g. `ecom/agent-pipeline`), unique within its workspace and case-insensitive. It is chosen at
registration and cannot be changed afterwards. Deleting a prompt does not free its name for reuse.

**Rationale**: The name is what consumer code hard-codes, so it is a public contract, not a label.
Renaming it silently breaks every caller — the exact class of failure `BRIEF.md` §3 says triggers
the developer veto. Retiring the prompt is the supported path, not renaming it.

**Impact if wrong**: An alias table plus a redirect in the resolver. Contained, but every stored
usage record would need its name resolved through the alias to stay readable.
