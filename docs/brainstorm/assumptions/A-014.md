# A-014 — Every state change writes an append-only property-history event

**Statement**: Registration, edit, access grant, ownership transfer, submission, approval,
request-changes, release, restore, and retirement each append one immutable event carrying actor,
action, target (prompt and version ID), timestamp, and an optional reason. Events are never updated
or deleted.

**Rationale**: NFR-02 requires every production release to be traceable to owner, revision,
decision, and usage context, and `BRIEF.md` §7 states the design law that every operational field
must be produced by an action someone was already taking. An append-only event log is the mechanism
that makes both true without asking anyone to remember anything.

**Impact if wrong**: Adding event types is routine; removing the log is not on the table.
