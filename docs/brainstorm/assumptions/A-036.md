# A-036 — An AI-generated fallback answer is a proposal, never a live artefact

**Statement**: Generating a fallback answer with a model produces a **draft revision** that a human
must review and approve like any other. It is never written directly onto a released revision. At
most one pending generated candidate exists per prompt at a time.

**Rationale**: The user's answer allows "AI generate trước", and this records the boundary that
makes it safe. `BRIEF.md` §8 sets the agent's legitimate jobs and the quantity discipline — at most
one candidate awaiting a decision per prompt, always as a proposed revision the user accepts or
discards. A generated fallback is content served to end users under the company's name, so it is
exactly the case where that discipline matters most.

**Impact if wrong**: This is a guard rail, not a mechanism. Removing it would mean model-written text
reaching users with no human in the loop, which contradicts BR-04.
