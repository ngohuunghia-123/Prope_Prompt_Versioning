# A-009 — Break-glass release is in the MVP

**Statement**: A release may proceed without an approval record if the actor supplies a one-line
reason. Such a release is stored with `break_glass = true`, the reason text, and the actor, and it
creates a review task due within 24 hours. Break-glass releases are excluded from the "100% of
releases carry an approval record" metric and counted separately.

**Rationale**: `BRIEF.md` §5② calls break-glass mandatory, with the stated reason that without an
escape hatch people route around the gate permanently. It costs one boolean, one text field, and one
task row.

**Impact if wrong**: Removing it is deleting a code path.
