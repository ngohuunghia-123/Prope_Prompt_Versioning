# A-062 — A prompt property carries several named eval suites, each versioned and run independently

**Statement**: A prompt property owns one or more eval suites, each with a name the author chooses
(`safety`, `accuracy`, `format`, …), unique within that prompt. Each suite is versioned separately
(A-004) and holds its own 10–20 cases and its own `output_modality` (A-061).

- Submitting a revision for review runs **every** suite the prompt currently has, one `eval_run` per
  suite. A reviewer may re-run a single suite.
- Comparison, baseline pairing, and cost delta are **per suite** — the baseline rule in ADR-0004 already
  keys on `suite_id`, so it needs no change.
- The review summary carries a per-suite row plus a rollup. `requires_acknowledgement` (A-058) is true
  when **any** suite has a failing case. The total cost delta is the sum across suites, and it is
  withheld whenever any suite withheld its own (A-057) — a total over 4 of 5 suites reads as a saving.
  The per-suite deltas that are valid are still shown.

**Rationale**: User decision, 2026-08-08. A prompt has more than one thing that can be true about it at
once, and folding them into one list of 20 cases makes the result unreadable: "3 failed" does not say
whether the prompt got less safe or merely changed its output format, and those two deserve different
reactions from a reviewer. Named suites make the failure legible on the screen where the decision is
actually made.

A-004's argument is untouched and now applies per suite: the same suite version measures both revisions,
so the comparison stays apples-to-apples. Nothing about the yardstick weakens; there are simply several
yardsticks, each labelled.

**Impact if wrong**: The suite's identity key gains a column and the review summary becomes a list. The
real cost is not schema — it is dispatch volume: N suites multiply the upstream calls on one workspace's
own key, which is why the concurrency bound becomes global rather than per-run (A-063) and why baseline
reuse (ADR-0004) matters more than it did with one suite.
