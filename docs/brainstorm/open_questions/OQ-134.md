# OQ-134 — INT-029 says fifteen routes; an enumeration of its own list gives sixteen

**Raised by the access-control build, 2026-08-11.** `blocks_build: false` — sixteen operations
shipped and `tests/architecture/test_route_table.py` asserts sixteen against a literal list.

## The discrepancy

INT-029's prose says *"15 routes"*. The lock file says the tombstone route took the count *"from 14 to
15"*. Enumerating the paths either document prints gives **sixteen operations across thirteen paths**:

```
POST   /api/v1/auth/login                                  POST   /api/v1/prompts/{prompt_id}/grants
POST   /api/v1/auth/logout                                 DELETE /api/v1/prompts/{prompt_id}/grants/{user_id}
POST   /api/v1/auth/password                               GET    /api/v1/workspaces/{id}/keys
POST   /api/v1/workspaces                                  POST   /api/v1/workspaces/{id}/keys
GET    /api/v1/workspaces/{id}/members                     DELETE /api/v1/workspaces/{id}/keys/{key_id}
POST   /api/v1/workspaces/{id}/members                     GET    /api/v1/permissions
DELETE /api/v1/workspaces/{id}/members/{user_id}           POST   /api/v1/users/{user_id}/tombstone
PUT    /api/v1/workspaces/{id}/members/{user_id}/roles
GET    /api/v1/prompts/{prompt_id}/grants
```

Neither stated number matches, so this is not a paths-versus-operations confusion of the kind INT-028
resolves for call-ledger (*"5 routes"* beside four bullet lines). It is most likely a `GET|POST` pair
counted once somewhere.

## What is being asked

Confirm sixteen and amend the two counts, or name the route that should not exist.

Reversal cost: low. Removing a route is a deletion; the count assertions are literals.
