Pick a released prompt above and say something. This page sends only user and assistant messages — the system prompt is added by Prope from the released revision.

Agent chain mode instead runs one message through several released prompts — guardrail, planner, retrieval, sub-agent, answer — and threads them into one conversation you can then see drawn as a graph in Prope.

Legacy app mode is the opposite of both: this page stops being a Prope client and behaves like any other chatbot. Its system prompt comes from its own source, it names a model at the provider, and it sends no prope block at all. With an observing key, the gateway forwards the call and files what it saw — so the prompt shows up in Prope without this app being changed.
