An ordinary chatbot

This page holds its own system prompts and calls an OpenAI-compatible endpoint with a provider model name. It has no idea Prope exists. Point it at Prope's gateway with an observing key and every call is answered normally while Prope files the prompt it saw.

  1. Set gateway and api key in Settings. Nothing else.
  2. Type a provider model name — gpt-4o-mini, gemini-2.5-flash.
  3. Send a few messages, switching persona partway.
  4. Run python seed.py --observations to see what was filed.

Enter to send · Shift+Enter for a new line

Settings

Two fields. This is the whole integration — the same two lines a product already edits to point at any OpenAI-compatible endpoint. Kept in this browser's localStorage; a real product keeps its key on a server.

Prompts in this app

Hardcoded in index.html, near the bottom, in APP_PROMPTS — where a real product keeps them. Prope has never been given any of this text. Two of the three interpolate today's date, which is what makes them arrive as one observation with an inferred variable rather than a new one every day.
